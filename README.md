# Сервис модерации объявлений

## Запуск

```bash
pip install -r requirements.txt
fastapi dev
```

Документация: http://127.0.0.1:8000/docs

## Тесты

```bash
pytest
```

## Структура

- `routers/` - обработчик `POST /predict`, валидация входа, коды ответа
- `services/` - бизнес-логика модерации
- `repositories/` - хранение результатов модерации
- `models/` - pydantic-схема объявления

## Логика

Подтвержденный продавец => `true`
Неподтвержденный продавец => `true` только если `images_qty > 0`

## Коды ответа

- 200 - предсказание, тело ответа - `true` / `false`
- 400 - невалидные входные данные
- 500 - ошибка при выполнении предсказания
